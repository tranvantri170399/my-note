Kho tài khoản cá nhân

Mã hóa đầu cuối AES-256-GCM ngay trên trình duyệt, lưu duy nhất vào file data.json trên Private GitHub Gist của bạn.

Đã nhớ GitHub Token trên máy này
Chỉ cần quyền gist. Chỉ lưu tạm ở localStorage máy bạn.
Master Password không bao giờ được lưu hay gửi lên mạng.
Hướng dẫn lấy GitHub Token (30 giây)
  1. Vào GitHub Settings → Developer settings → Personal access tokens.
  2. Tokens (classic): chỉ tích quyền gist. Hoặc Fine-grained: Account permissions → Gists: Read and write.
  3. Dán Token vào ô trên và đặt Master Password. Lần đầu web sẽ tự tạo Private Gist chứa data.json đã mã hóa.
