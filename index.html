My Note Vault

Kho tài khoản cá nhân

Mã hóa đầu cuối AES-256-GCM ngay trên trình duyệt, lưu duy nhất vào file data.json trên Private GitHub Gist của bạn.

Đã nhớ GitHub Token trên trình duyệt này
Chỉ cần cấp duy nhất quyền gist. Chỉ lưu tạm ở localStorage máy bạn.
Master Password không bao giờ lưu xuống ổ cứng hay gửi lên mạng.
Hướng dẫn lấy GitHub Token (30 giây)
  1. Vào GitHub Settings → Developer settings → Personal access tokens → Tokens (classic) (hoặc Fine-grained tokens → Gists: Read & Write).
  2. Tạo token mới và chỉ tích chọn quyền gist (Create gists).
  3. Dán Token vào ô trên và đặt một Master Password. Lần đầu web sẽ tự tạo một Private Gist chứa data.json đã mã hóa.
